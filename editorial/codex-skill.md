# Codex cryptic clue composer skill

This repository provides `.agents/skills/cryptic-clue-composer/SKILL.md` as an agent skill. It complements, rather than replaces, the versioned example library in `editorial/clue-examples.json`.

Invoke the skill when composing or reviewing cryptic clues. The agent should consult the examples, explore multiple devices and creative starting points, verify exact constructions and document why some candidates are rejected.

To extend its repertoire, add a properly annotated example to the JSON library. No change to the skill's core instructions is necessary. The skill is not a training/fine-tuning process and does not itself make the composer autonomous or guarantee clue quality.
